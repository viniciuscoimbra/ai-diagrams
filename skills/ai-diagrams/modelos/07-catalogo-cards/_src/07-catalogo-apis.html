■ Catálogo conceitual em cards

Catálogo das APIs da plataforma

Cinco APIs, uma por card. Cada card traz quando usar, o que a API entrega, o time dono e o nome do contrato.
A01
Contas
Use quando
Precisa abrir, bloquear ou consultar uma conta.
Entrega
Conta, situação e saldo atual.
Dono
Time de contas.
api-contas-v1
A02
Pagamentos
Use quando
O cliente paga, transfere ou agenda um pagamento.
Entrega
Ordem criada, idempotente, com evento publicado.
Dono
Time de pagamentos.
api-pagamentos-v1
A03
Extrato
Use quando
A tela mostra lançamentos de um período.
Entrega
Lançamentos paginados, em ordem de data.
Dono
Time de extrato.
api-extrato-v1
A04
Cadastro
Use quando
Precisa dos dados ou da situação do cliente.
Entrega
Cliente, endereços e consentimentos.
Dono
Time de onboarding.
api-cadastro-v1
A05
Notificações
Use quando
Um evento precisa chegar ao cliente.
Entrega
Push, e-mail ou SMS, conforme preferência.
Dono
Time de engajamento.
api-notificacoes-v1
Toda API nova entra no catálogo antes do primeiro consumidor.
O contrato mora no repositório da API; o catálogo aponta para ele.
