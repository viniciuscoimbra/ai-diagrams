Relações
1
Cliente → App. Informa chave e valor e confirma com a senha.
2
App → API Pix. Envia o pedido com idempotency-key; recebe a situação.
3
Analista → Backoffice. Consulta transferências e pede devolução.
4
Backoffice → API Pix. Usa a mesma API, com o papel de operador.
5
API Pix → DICT. Resolve a chave para conta e banco do recebedor.
6
API Pix → Antifraude. Pede o score; sem resposta em 150 ms, segue como 0,5.
7
API Pix → Banco Pix. Grava o pedido e a linha da outbox no mesmo commit.
8
Worker → Banco Pix. Lê a outbox e atualiza a situação do pedido.
9
Worker → SPI. Envia o pacs.008 e recebe o pacs.002.
10
Worker → Core bancário. Debita a conta antes do envio; estorna se o SPI rejeitar.
