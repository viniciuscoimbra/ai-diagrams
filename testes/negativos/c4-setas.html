Relações
1
Cliente PJ → Portal PJ. Acessa a tela de emissão em lote e o painel de recebimentos.
2
Portal PJ → API de cobrança. Envia pedido de emissão; recebe linha digitável.
3
Cliente PJ → API de cobrança. Emite boletos pela API, com autenticação.
4
Analista financeiro → Backoffice. Consulta boletos e faz ajustes manuais.
5
Backoffice → API de cobrança. Usa a mesma API, com papel de operador.
6
API de cobrança → Banco de cobrança. Grava boleto, situação e eventos.
7
API de cobrança → CIP. Registra cada boleto antes de devolver a linha digitável.
8
Banco liquidante → Processador de retorno. Envia arquivo CNAB 240 por SFTP para bucket; evento do bucket aciona fila SQS.
9
Processador → Banco de cobrança. Lê arquivo de retorno e atualiza situação do boleto.
10
Processador → Webhook do cliente. Avisa o cliente PJ a cada boleto pago, com assinatura HMAC.
11
Processador → ERP contábil. Envia lançamento de cada baixa por evento no EventBridge.
