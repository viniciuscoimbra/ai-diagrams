API de pagamentos e extrato assíncrono

O app do cliente cria um pagamento pela API; o serviço grava no Aurora e publica o evento no EventBridge. O extrato consome o evento por uma fila SQS e mantém a própria visão no DynamoDB.

Passos
1
O app do cliente chama POST /pagamentos com o token da sessão.
2
O API Gateway valida o token no Cognito antes de seguir; token inválido volta 401.
3
A requisição chega à Lambda pagamentos, que valida o payload e a idempotência.
4
O pagamento é gravado no Aurora; esta é a fonte da verdade do domínio.
5
Depois do commit, a Lambda publica o evento no EventBridge do domínio.
6
Uma regra roteia o evento pagamento criado v1 para a fila do extrato.
7
A Lambda extrato consome a fila em lotes; falha repetida vai para a DLQ.
8
O lançamento entra no DynamoDB, que serve a tela de extrato do app.
